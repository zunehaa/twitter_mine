How It Works

A transparent 3-step sentiment prediction pipeline.

01

1. Enter Comment

Paste or type any Twitter comment into the analyzer field. The text is passed securely to the backend engine.

02

2. Preprocess & Vectorize

The text undergoes lowercasing, URL/mention stripping, and TF-IDF n-gram vectorization matching the exact training pipeline.

03

3. Model Inference

The trained machine learning classifier evaluates feature weights to calculate exact probabilities for Positive, Negative, Neutral, or Irrelevant sentiment.
